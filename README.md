# Spicetify Apps

A collection of custom apps for [Spicetify](https://spicetify.app).

---

## [Data Porter](apps/data-porter/README.md)

Export and import your Spotify library data -- playlists, liked songs, albums, artists, and podcasts.

---

### Installation

Each app has one-liner install scripts. See the app's README for details.

**Linux / macOS:**

```sh
curl -fsSL https://raw.githubusercontent.com/Prog-Jacob/spicetify-apps/main/install.sh | bash -s <app-name>
```

**Windows (PowerShell):**

```ps1
iex "& { $(iwr -useb https://raw.githubusercontent.com/Prog-Jacob/spicetify-apps/main/install.ps1) } <app-name>"
```

Replace `<app-name>` with the app you want to install (e.g. `data-porter`).
